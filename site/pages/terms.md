页首说明：

> 本站收录公开发表的论文题目、摘要与链接，用模型生成中文精读与推荐理由，原文版权归各期刊、会议与作者所有。网页、RSS、公开 API 与 MCP 均可匿名使用；账号用于收藏（含分组和标签）、阅读状态、笔记和保存搜索的同步；订阅的 RSS 地址请勿公开。

## 1. 内容与版权

本站展示的论文题目、作者、期刊与摘要来自公开的出版信息与预印本平台，中文精读和推荐理由由模型根据这些材料生成，可能有误，重要结论请以原文为准。每篇精读都标注为 AI 生成，并尽量给出段落依据。

原文版权归各期刊、会议与作者所有。本站不转载论文全文，只展示摘要级别的信息和原文链接；引用原文的句子用于说明结论的适用范围。预印本尚未经过同行评审，引用时请谨慎；正式发表版本以期刊页面为准。

## 2. 作者与出版方的更正与下架

如果你是论文作者或出版方，希望更正题目、摘要、作者顺序，或要求下架某篇条目，请通过反馈页联系我们并说明是哪一篇（附 DOI 或 arXiv 编号最快），我们会尽快处理。撤稿的论文会标注并停止推荐。

## 3. 账号

- 用户名和密码由你设置并自行保管；注册时生成的十串恢复码请自己保存，忘记密码时用其中任意一串重置，每串只能用一次。
- 一个人可以注册一个账号，请不要冒用他人或机构的身份注册。
- 账号用于收藏、阅读状态、笔记和订阅的同步；这些个人数据默认私有，只有你本人能看到。
- 注销会立即删除账号、登录会话和恢复码，不能恢复。
- 用自动程序批量注册、发送垃圾内容或绕过频率限制的账号，我们可能限制或删除。

## 4. 使用本站的数据

个人阅读、教学与科研内部使用不需要事先申请。以下用途请先取得同意：把本站的中文精读整体转载到公开渠道、把数据用于商业产品、批量再分发或训练模型。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试；抓取时请带上能识别自己的 User-Agent。

## 6. 你不可以做什么

- 大规模抓取网站内容，或绕过访问频率限制。
- 冒充本站、其他用户或论文作者。
- 攻击、探测或干扰网站的正常运行。
- 用自动程序注册大量账号，或发送垃圾内容。
- 把本站生成的中文精读当作原创内容发表。

## 7. 免责

本站按“现状”提供，不保证收录完整、摘要准确或服务持续可用。本站不是论文的正式发表渠道，引用请以原文和正式出版版本为准。引用导出（BibTeX、RIS、APA、GB/T 7714）来自公开元数据，作者名或标题偶尔会有错误，使用前请对照原文核对。

## 8. 变更与申诉

本规则自上线之日起适用。我们可能修改本规则，修改前会在网站上通知。对账号处理有异议的，可以通过反馈页申诉。

## 9. 联系我们

查询、更正、删除资料或申诉，请通过「反馈」页联系我们。
