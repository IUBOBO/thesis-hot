## 一、隐私说明

### 1. 我们收集什么

| 数据 | 什么时候收集 | 用途 | 保存在哪里 |
|---|---|---|---|
| 邮箱地址 | 注册或登录时 | 发送登录验证码；发送你订阅的提醒（如你开启） | 服务器数据库 |
| 收藏、文献库分组、标签、阅读状态、笔记 | 你在网站上操作时 | 在你的设备之间同步 | 服务器数据库，只有你本人可见 |
| 搜索关键词 | 你搜索时 | 返回搜索结果；【待定：是否保存搜索历史，以及保存多久】 | 【待定】 |
| 阅读记录（已读标记） | 你打开一篇论文时 | 标记已读、在列表中淡化显示 | 浏览器本地存储；登录后同步到服务器 |
| 登录状态 | 登录后 | 保持登录 | 浏览器 Cookie（只读写一个登录凭证） |
| 访问日志（IP、时间、访问页面、浏览器类型） | 每次访问 | 保证服务安全、排查故障、防止滥用 | 服务器日志，【待定：保存多少天】 |

我们不收集你的姓名、手机号、身份证号或其他身份信息。【待定：是否需要学校或单位信息】

### 2. 我们不做什么

- 我们不出售你的个人数据。
- 我们不把你的收藏、笔记、搜索记录公开。热度榜里如果用到收藏数，只使用汇总数字，不显示任何个人信息。
- 我们不在网站上展示广告。【待定：如果以后加广告，这一条要改】

### 3. 第三方服务

网站会向以下服务发出请求，它们可能收到你的 IP 地址和访问的页面：

| 服务 | 用途 | 它会收到什么 |
|---|---|---|
| OpenAlex | 获取论文的引用数、作者和卷期等公开信息 | 只请求公开的论文编号，不发送你的个人信息 |
| Cloudflare | 网站的域名解析、加速和安全防护（Cloudflare Tunnel） | 你的 IP 地址、访问的页面、浏览器信息 |
| 邮件服务【待定：选哪一家】 | 发送登录验证码 | 你的邮箱地址和验证码内容 |

### 4. Cookie 和本地存储

- 登录凭证：一个 Cookie，用来保持登录，有效期【待定：天数】。
- 本地存储：保存你的阅读记录、界面设置（如深色模式、字体）和未登录时的收藏。这些只在你的浏览器里，清除浏览器数据后会丢失。
- 我们不使用广告追踪 Cookie。【待定：是否使用访问统计工具，如使用，写明名称】

### 5. 数据保存多久

- 账号数据：账号存在期间保留；注销后【待定：__ 天内删除】。
- 收藏与笔记：账号存在期间保留；你删除后立即从服务器移除。
- 访问日志：【待定：保存 __ 天】。

### 6. 你的权利

- 查看：你可以在“我的”页看到收藏、文献库和订阅。
- 导出：你可以导出收藏和笔记为 BibTeX、Markdown 或 CSV 格式。【待定：导出功能是否在第一批上线】
- 删除：你可以删除单条收藏或笔记，也可以注销账号，注销后数据按第 5 条删除。
- 联系我们：发送邮件到【待定：联系邮箱】。

### 7. 儿童

网站面向研究者和在校学生，不专门面向未满 【待定：__ 周岁】 的人。如发现未成年人的个人信息被误收集，请联系我们删除。

## 二、使用规则

### 1. 你可以做什么

- 在个人学习和研究中阅读、收藏、导出引用。
- 通过 RSS、公开 API 或 MCP 接入自己的工具，遵守接口的访问频率限制。
- 引用论文时，以原文为准，并注明出处。

### 2. 你不可以做什么

- 大规模抓取网站内容，或绕过访问频率限制。
- 把网站内容（包括中文精读）当作原创发表。
- 冒充网站或其他人。
- 用自动程序注册大量账号或发送垃圾邮件。
- 攻击、探测或干扰网站的正常运行。

### 3. 内容说明

- 论文题目、摘要和链接来自公开信源，版权归原期刊、会议和作者所有。
- 网站不转载论文全文。开放获取的论文可以链接到原文或 arXiv 版本。
- 中文精读和推荐理由由 AI 生成，仅供参考，以原文为准。每段都标注了“AI 生成”，并可以对照英文摘要。
- 热度榜的数字来自引用、讨论和代码等信号，不代表论文的最终质量。
- 预印本尚未经过同行评审，请谨慎引用。

### 4. 引用导出

导出的 BibTeX 和 RIS 来自公开的元数据，作者名或标题偶尔会有错误。使用前请对照原文核对。

### 5. 我们可能采取的措施

如果你违反上述规则，我们可能限制访问、暂停账号或删除相关内容。【待定：申诉方式】

### 6. 免责

- 网站按“现状”提供，不保证内容完整、准确或持续可用。
- 因使用网站内容造成的损失，我们在法律允许的范围内不承担责任。【待定：是否需要更正式的责任条款，建议请专业人士确认】

本规则自【待定：生效日期】起适用。我们可能修改本规则，修改后会在网站上通知。
