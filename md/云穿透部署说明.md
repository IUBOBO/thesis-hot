# 对外访问：Cloudflare Tunnel 部署说明（D1）

> 目标：电脑保持开机，网站通过 Cloudflare Tunnel 对外提供访问，不直接暴露本机 IP 和端口。
> 状态：说明已写好。需要你的 Cloudflare 账号、域名和 Tunnel 令牌后，才能实际启用。

## 一、前提

- 一个 Cloudflare 账号，并且域名的 DNS 已经托管到 Cloudflare。
- 本机已经能跑通网站（参考 `LOCAL.md`）：
  - 网页在 `127.0.0.1:3100`
  - API 在 `127.0.0.1:3001`
- 站点地址（`SITE_URL`）填写你的域名，例如 `https://thesis.example.com`。【需要你提供域名】

## 二、安装 cloudflared

Windows 上可以用 winget 安装：

```powershell
winget install --id Cloudflare.cloudflared
```

安装后确认版本：

```powershell
cloudflared --version
```

## 三、创建 Tunnel

在 Cloudflare 控制台：

1. 进入 **Zero Trust → Networks → Tunnels**，点击 **Create a tunnel**。
2. 类型选择 **Cloudflared**，给 Tunnel 起一个名字，例如 `thesis-nh`。
3. 控制台会给出一条安装命令，里面包含 **Tunnel 令牌（token）**。【需要你复制这个令牌，妥善保存，不要提交到仓库】
4. 在 **Public Hostname** 里添加一条规则：
   - 域名：`thesis.example.com`【替换为你的域名】
   - 服务类型：`HTTP`
   - 服务地址：`localhost:3100`

网页服务会把 API 请求转给 API 服务（`3001`），所以只需要指向网页服务。

## 四、启动 Tunnel

把令牌放进环境变量（只在当前窗口生效）：

```powershell
$env:TUNNEL_TOKEN = "<你的令牌>"
cloudflared tunnel run
```

长期运行可以注册成 Windows 服务，参考 Cloudflare 官方文档的 `cloudflared service install`。注册时同样使用令牌。

## 五、检查

1. 打开 `https://thesis.example.com`，能看到首页。
2. 打开 `https://thesis.example.com/api/site/meta`，返回 JSON。
3. 在另一台设备（例如手机流量）上访问同一域名。

## 六、安全注意事项

- **不要**把 3100、3001、5432 端口在路由器上做端口转发。Tunnel 是向外连接，不需要开放入站端口。
- 数据库只监听本机（`127.0.0.1`），不要改成 `0.0.0.0`。
- `.env` 里的密钥不要提交到仓库，也不要发给别人。
- 令牌泄露后，在 Cloudflare 控制台**轮换令牌**。
- 站点设置里的 `SITE_URL` 必须是 `https://` 开头的域名，否则分享链接和 RSS 地址会错。

## 七、电脑关机或睡眠时

- 电脑关机或睡眠时，网站不可访问。
- 需要在电脑上关闭“睡眠”，并设置“接通电源时永不睡眠”。
- 开机自启：参考 `LOCAL.md`，让数据库、API、worker、网页和 Tunnel 都随系统启动。

## 八、需要你提供的信息

| 编号 | 信息 | 用途 |
|---|---|---|
| 1 | 域名（例如 `thesis.example.com`） | 配置 Public Hostname 与 `SITE_URL` |
| 2 | Cloudflare Tunnel 令牌 | 启动 Tunnel（只在你的电脑上保存） |
| 3 | 是否注册 Windows 服务，让 Tunnel 开机自启 | 决定安装方式 |
